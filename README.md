## Smart German Vocabulary Trainer

Android application designed to help learners improve their German vocabulary using **color-coded articles** and a **flashcard-based learning system**.

---

## ✨ Features

* Color-coded German articles (**der, die, das**) to support faster memorization
* Flashcard-based vocabulary learning
* Tap the flashcard to reveal the meaning
* Shuffle button to randomize the order of words
* Word pronunciation button for both German and English
* Favorite button
* Simple and clean user interface

---

## 📚 Vocabulary

Vocabulary can be added in two ways:

* **Preloaded vocabulary list** included in the app for beginner learners
* **Manually added words**, where users can enter:

  * Article (der / die / das)
  * Word
  * Plural form
  * English meaning
  * An example German sentence for the word
